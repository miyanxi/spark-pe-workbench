# 演示流程

1. 按 README 安装依赖，双击 `start_demo.bat`，通过 `http://127.0.0.1:8000/` 访问。演示数据不需要 API Key，不要直接双击 HTML。
2. 在全新空数据库载入演示数据：3 班、30 人、60 条记录。
3. 选择班级，查看档案、两期成绩、班级分析、雷达图与趋势。
4. 下载模板，用虚构名单演示预览校验；确认导入会写入本地数据库。
5. 配置可用模型及额度后展示教案或训练方案，结果需教师复核。

重复载入不会清空已有班级。需要重做演示时，请备份并使用新的独立环境，不要覆盖真实数据。默认数据库为 `data/spark.db`。

重新生成 JSON（不改数据库、不需要 API）：

```powershell
python scripts/generate_demo_data.py
```

固定种子生成虚构样本。本地演示可无密钥启动，AI 生成功能仍需自己的有效密钥。后续计划补充首页、名单校验、分析和备课结果截图与录屏；当前尚未制作素材、未部署线上地址。
