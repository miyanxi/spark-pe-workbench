# 隐私与脱敏

候选副本不含原数据库、真实配置、上传导出文件、客户交付文档、压缩包、安装包、虚拟环境及旧 Git 历史。

`demo_data.json` 由 `scripts/generate_demo_data.py` 独立生成，学校、班级、学生编号、姓名和成绩均为虚构，健康标记为空。它们只演示流程，不证明评分算法的专业准确性。前端默认学校名改为“SPARK 演示学校”。

配置模板密钥为空。请在本地配置或环境变量使用自己的密钥，不要提交真实密钥或将其带入截图、模型提示和报告。

忽略规则无法清除旧 Git 历史。最终检查后应以候选副本建立新仓库，不推送整个原项目或本地 audit 目录。截图录屏须使用独立虚构数据，检查账户、路径及模型输出后再发布。当前未附截图录屏。
