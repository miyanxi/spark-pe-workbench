# 源码基线选择

原项目有根目录版和客户交付子目录版。本副本选择客户交付版源码，因为其名单预览确认、SQLite 外键、模型错误提示、本地图表资源及空数据库演示载入保护更完整。

保留后端逻辑及依赖版本，仅重写公开说明、清空配置模板密钥、强化忽略规则、替换前端默认学校名，并独立生成虚构数据。未复制客户配置、数据库及交付包。

这不代表所有功能均已生产验收或已完成部署改造。两个原始版本均保留，未删除或覆盖。

2026-11-19 启动体验修复：公开副本新增 Windows/跨平台本地启动入口；缺少本地配置时使用空密钥模板；将密钥检查推迟到实际 AI 调用，允许无密钥浏览本地演示数据；直接打开 HTML 时显示启动指引。此后 `config.py` 和 `deepseek_client.py` 不再与原版逐字节相同。
